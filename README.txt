====================================================
موقع وداشبورد عيادة رنيم Raneem Clinic — دليل الرفع على Hostinger
====================================================

المحتويات:
- index.php ...................... الموقع الرئيسي (يقرأ كل شيء من قاعدة البيانات)
- assets/ ......................... تنسيق وسكربت الموقع
- admin/ .......................... لوحة التحكم (الداشبورد)
- uploads/ ........................ الصور المرفوعة من الداشبورد
- config.php ...................... إعدادات الاتصال بقاعدة البيانات (يجب تعديلها)
- install.sql ..................... ملف قاعدة البيانات (استورديه أولاً)

--------------------------------------------------
الخطوة 1: إنشاء قاعدة بيانات MySQL في Hostinger
--------------------------------------------------
1. ادخلي إلى hPanel > Databases > Databases
2. أنشئي قاعدة بيانات جديدة (مثال: u123456789_raneem)
3. أنشئي مستخدم قاعدة بيانات (مثال: u123456789_admin) وكلمة سر قوية
4. اربطي المستخدم بقاعدة البيانات وامنحيه كل الصلاحيات (All Privileges)
5. احفظي: اسم القاعدة / اسم المستخدم / كلمة السر — ستحتاجينها بالخطوة القادمة

--------------------------------------------------
الخطوة 2: استيراد ملف قاعدة البيانات
--------------------------------------------------
1. من hPanel افتحي phpMyAdmin للقاعدة التي أنشأتها
2. اضغطي على تبويب "Import" / "استيراد"
3. اختاري ملف install.sql من هذا المجلد واضغطي "Go" / "تنفيذ"
4. سيتم إنشاء كل الجداول تلقائياً مع بيانات افتراضية (خدمات، صور، آراء عملاء تجريبية)
   ومستخدم دخول افتراضي:
       اسم المستخدم: admin
       كلمة السر:   (ضعي هاش كلمة السر في install.sql مكان PASTE_PASSWORD_HASH_HERE)
   *** غيّري كلمة السر فوراً بعد أول دخول من صفحة "إعدادات الدخول" داخل الداشبورد ***

--------------------------------------------------
الخطوة 3: رفع الملفات
--------------------------------------------------
1. من hPanel > File Manager (أو عبر FTP) ادخلي إلى مجلد public_html (أو المجلد الخاص بدومينك)
2. ارفعي كل محتويات هذا المجلد (وليس المجلد نفسه) إلى public_html
   بحيث يصبح المسار: public_html/index.php وليس public_html/raneem-clinic/index.php
3. تأكدي أن الصلاحيات على مجلد uploads/ تسمح بالكتابة (755 أو 775)

--------------------------------------------------
الخطوة 4: تعديل ملف الإعدادات config.php
--------------------------------------------------
افتحي ملف config.php وعدّلي:

    define('DB_HOST', 'localhost');
    define('DB_NAME', 'اسم قاعدة البيانات التي أنشأتها');
    define('DB_USER', 'اسم مستخدم القاعدة');
    define('DB_PASS', 'كلمة سر القاعدة');
    define('SITE_URL', 'https://دومينك.com');

--------------------------------------------------
الخطوة 5: الدخول إلى لوحة التحكم
--------------------------------------------------
افتحي المتصفح على: https://دومينك.com/admin/login.php
سجّلي الدخول بـ admin / admin123 ثم غيّري كلمة السر فوراً من "إعدادات الدخول".

--------------------------------------------------
محتويات لوحة التحكم
--------------------------------------------------
✓ تعديل كل نصوص الموقع (العنوان، الوصف، معلومات التواصل...)
✓ تغيير رابط فيديو الريلز في الصفحة الرئيسية
✓ إدارة الخدمات المعروضة في الموقع
✓ إدارة معرض الصور (رفع/حذف/تعديل)
✓ إدارة آراء العملاء
✓ إدارة الزبائن (إضافة، بحث، عرض إجمالي ما أنفقته كل زبونة)
✓ تسجيل عمليات الزبائن مصنّفة حسب النوع:
   تجميل، مناكير، بديكير، حمام مغربي، تصفيف شعر، قص شعر، صبغة وأظافر، رموش، جلسات ليزر
✓ إدارة الموظفين وتسجيل صرف الرواتب شهرياً
✓ تسجيل مصاريف المواد ومصاريف المركز (إيجار، كهرباء...)
✓ تقرير أرباح شهري: الإيرادات − تكلفة المواد − المصاريف − الرواتب = صافي الربح
✓ تغيير اسم المستخدم وكلمة سر الدخول للداشبورد من داخل الداشبورد نفسه

--------------------------------------------------
ملاحظات مهمة
--------------------------------------------------
- رابط فيديو الريلز يجب أن ينتهي بـ /embed/ حتى يعمل بشكل صحيح
  مثال: https://www.instagram.com/reel/DZqWIYGRPDK/embed/
- إذا رغبتِ بإضافة تصنيف جديد لعمليات الزبائن، عدّلي الملف:
  admin/includes/operation_types.php
- ملف install.sql محمي تلقائياً عبر .htaccess من الوصول المباشر من المتصفح
- يفضّل تفعيل SSL (https) من hPanel > SSL قبل نشر الموقع نهائياً
